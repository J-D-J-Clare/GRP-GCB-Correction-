# GRP-GCB-Correction-
This contains data/code for the Correction to article *Correction to “A cloudy forecast for species distribution models: Predictive uncertainties abound for California birds after a century of climate and land-use change”* in Global Change Biology (https://doi.org/10.1111/gcb.70092).

An error was found (much later, unfortunately) in code that aggregated incidence data for the initial analysis. The short of it is that 30-40% of the inputs for the analysis were incorrect: species were mistakenly reported as observed at locations/times when they were not observed (and the opposite as well). The data objects here encompass the corrected data. We also include a script for running the most full model and deriving its LOOIC score.
